Профиль, который похож на вас

Баннер, цвета профиля, рамки для аватара, эффекты и стили имени — всё бесплатно. Добавляйте друзей по имени пользователя, ставьте статус и общайтесь в личных сообщениях даже без общих серверов.

Ваши разговоры — ваши

Нет компании, которая владеет вашими данными: каждый сервер принадлежит тому, кто его поднял.

🔒

Сквозное шифрование

Личные и групповые сообщения можно зашифровать на устройствах (протокол MLS). Сервер видит только шифротекст — и файлы тоже.

🌐

Нет центрального сервера

Свой сервер — одна команда docker compose up -d. Заблокировать или выключить «весь NeoShard» нельзя.

📖

Полностью открытый код

Сервер, клиенты и протокол — на GitHub под GPL/AGPL. Никакой сторонней аналитики: всё работает на вашем сервере.

🎁

Никаких подписок и платных функций: рамки, эффекты профиля и темы — для всех. Без рекламы и профилирования.
