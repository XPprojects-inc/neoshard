# ADR-0014: Федерация между инстансами
- Статус: принято · 2026-10-18
## Решение
«Домашний инстанс гильдии»: гильдия живёт на одном инстансе, пользователи других инстансов присоединяются как
удалённые участники `user@instance`. Инстансы общаются по HTTPS `POST /federation/v1/...`, запросы подписаны
Ed25519-ключом инстанса (заголовки `NeoShard-Origin`, `NeoShard-Date`, `NeoShard-Signature`), публичный ключ —
в `/.well-known/neoshard`. Домашний инстанс — авторитет по порядку и правам.
## Отклонено
DAG-репликация (Matrix) — тяжело и медленно; ActivityPub — не для realtime-чата.
