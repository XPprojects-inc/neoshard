# ADR-0022: Публичные серверы и вступление по названию
- Статус: принято · 2026-10-20

## Контекст
Вступить на сервер можно было только по коду приглашения. Пользователи ищут серверы по
названию, а в приложениях ссылки-приглашения вели на `tauri.localhost`.

## Решение
- **Хранение.** У гильдии появляются флаг `discoverable` и описание `discovery_description`
  (до 300 символов), миграция 0007. По умолчанию флаг выключен: публичным сервер делает
  владелец, либо при создании, либо в настройках («Обзор → Публичный сервер»), и для этого
  нужно право `MANAGE_GUILD`. Изменение пишется в журнал аудита.
- **API:**
  - `GET /discovery/guilds?q=` — до 25 публичных серверов, крупные первыми.
  - `POST /discovery/guilds/{id}/join` — вступление без приглашения. Действуют те же лимит
    (200 серверов) и баны, что и для приглашений. Приватный сервер неотличим от
    несуществующего (404).
  - `GET/PUT /guilds/{id}/discovery` — настройка.
- **Поиск без учёта регистра на любом языке.** Используется
  `lower(name COLLATE pg_c_utf8) LIKE` (PostgreSQL 17+), потому что локаль C базы не
  приводит кириллицу к нижнему регистру. Символы `%`, `_` и `\` в запросе экранируются.
  Индекс построен по тому же выражению.
- **Ссылки.** Ссылка-приглашение имеет вид `https://сервер/invite/КОД`. Caddy перенаправляет её
  на `/app/?invite=КОД`, и клиент открывает окно «Добавить сервер» с превью. Адрес сервера
  берётся из настроек клиента, а не из `location.origin`. Копирование переходит на запасной
  `execCommand`, если Clipboard API недоступен (Android WebView); на телефонах есть
  кнопка «Поделиться».

## Последствия
- Каталог существует в рамках одного сервера NeoShard. Межсерверный каталог — вместе с
  федерацией сообществ.
- Сервер со сторонней базой PostgreSQL ниже 17-й версии не применит миграцию 0007.
