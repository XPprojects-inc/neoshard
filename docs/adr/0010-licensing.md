# ADR-0010: Лицензии — клиент GPL-3.0, сервер AGPL-3.0, спецификация CC-BY-4.0
- Статус: принято · 2026-10-18
## Решение
- `crates/*`, `apps/*`, `packages/*` — **GPL-3.0-or-later**: форки клиентов остаются открытыми (как у Telegram-клиентов).
- `server/*` — **AGPL-3.0-or-later**: закрывает лазейку «модифицированный сервер как сервис без кода».
- `spec/` — **CC-BY-4.0**: протокол может реализовать кто угодно; сила экосистемы — в открытом протоколе.
## Последствия
Боты и клиенты, написанные **по спецификации** без кода ядра, не обязаны быть GPL. Клиенты поверх `neoshard-core` — обязаны.
`neoshard-proto` используется и сервером (AGPL совместима с GPL-3.0 по §13).
