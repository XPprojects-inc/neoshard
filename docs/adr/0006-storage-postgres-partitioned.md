# ADR-0006: PostgreSQL для всего, сообщения — hash-партиционированная таблица
- Статус: принято · 2026-10-18
## Контекст
ScyllaDB даёт масштаб на миллиарды сообщений, но удваивает операционную сложность self-host-инстанса.
## Решение
Postgres 16. `messages PARTITION BY HASH (channel_id)` на 16 партиций, PK `(channel_id, id)`.
Запросы — `sqlx` (async, без ORM), макросы `query!`/`query_as!` с проверкой на этапе компиляции; офлайн-кэш
`.sqlx/` (`cargo sqlx prepare`), чтобы сборка не требовала живой БД.
## Последствия
Официальный инстанс — Yandex Managed PostgreSQL. При > ~5 млрд сообщений — адаптер Scylla за трейтом хранилища сообщений.
