# ADR-0015: Плагины клиента в песочнице, темы, ребрендинг
- Статус: принято · 2026-10-18
## Решение
- Плагин = JS-модуль в `sandbox`-iframe без `allow-same-origin` (нет доступа к токену и DOM). Общение — `postMessage`
  с узким API по разрешениям из манифеста; пользователь подтверждает разрешения.
- Темы — JSON → CSS-переменные.
- Ребрендинг — один файл `neoshard.config.json`: имя, иконки, эндпоинты, feature flags.
