# ADR-0005: Snowflake ID вместо UUID
- Статус: принято · 2026-10-18
## Решение
64 бита: 42 бита мс от эпохи 2026-01-01T00:00:00Z, 10 бит worker id, 12 бит sequence. Хранится как `BIGINT`.
## Почему
Сортировка по времени бесплатна (пагинация истории по `id`), 8 байт против 16, varint в protobuf, нет координации.
Отклонено: UUIDv7 (16 байт), автоинкремент (утечка счётчиков, координация в кластере).
## Последствия
Worker id — из конфига узла (0..1023). В JSON — строкой (JS теряет точность выше 2^53).
