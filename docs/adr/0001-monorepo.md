# ADR-0001: Монорепозиторий
- Статус: принято · 2026-10-18
## Контекст
Протокол, сервер, ядро клиента и UI меняются согласованно; форкам нужно одно место.
## Решение
Один репозиторий: `crates/` (proto, core, examples), `server/` (члены корневого Cargo workspace),
`apps/web`, `apps/desktop`, `packages/ui`, `spec/`, `deploy/`, `docs/`. Один корневой Cargo workspace
(общий `Cargo.lock`), npm workspaces для JS (pnpm не обязателен — меньше входной порог для форков).
## Последствия
Атомарные изменения протокола; CI собирает всё. Форк UI может взять только `@neoshard/core`.
