# ADR-0009: Правила границы JS↔WASM
- Статус: принято · 2026-10-18
## Решение
1. Ядро отдаёт события **пакетами**: `drain() -> Uint8Array` (protobuf `UpdateBatch`), раз на кадр (rAF).
2. Команды — одним вызовом `dispatch(bytes)`; результаты приходят событиями.
3. Никаких геттеров «по полю»; UI держит копию состояния (Solid store), обновляемую из пакетов.
4. Строки через границу — только внутри protobuf-буфера (одна копия).
