# ADR-0017: Аутентификация — argon2id, opaque-токены сессий, TOTP
- Статус: принято · 2026-10-18
## Решение
- Пароли — argon2id (m=19 МиБ, t=2, p=1 — OWASP).
- Токен сессии — 32 случайных байта, `ns_<base64url>`; в БД — SHA-256. Боты — `nsb_`. JWT отклонён: отзыв мгновенный.
- 2FA — TOTP (RFC 6238, 6 цифр, 30 с, окно ±1), секрет зашифрован AES-256-GCM ключом из конфига; 10 backup-кодов.
- Вход с 2FA — `login` → `mfa_ticket` (5 мин) → `/auth/mfa/totp`.
- Восстановление — одноразовый токен по email (SMTP self-hosted/РФ), TTL 30 мин, хранится хэшем.
- Защита: dummy-хэш при неизвестном логине (одинаковое время), rate limit по IP.
