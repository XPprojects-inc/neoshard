# ADR-0013: E2EE для ЛС и групп — MLS (RFC 9420) через openmls
- Статус: принято · 2026-10-18
## Решение
Шифрсьют `MLS_128_DHKEMX25519_AES128GCM_SHA256_Ed25519`. Сервер хранит KeyPackage-ы и ретранслирует
Commit/Welcome/Application как непрозрачные байты, содержимое не видит. Ключи — в хранилище ядра.
Модуль e2ee в WASM — ленивый чанк (feature `e2ee`).
## Последствия
Поиск по E2EE-каналам — только локальный.
