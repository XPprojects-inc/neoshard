# ADR-0007: UI — SolidJS, без бизнес-логики
- Статус: принято · 2026-10-18
## Решение
SolidJS 1.9 + TypeScript + Vite. UI читает состояние из ядра (пакеты `Update` → Solid store) и шлёт команды.
Никакой проверки прав, ретраев, кэша в TS. Виртуализация ленты — `@tanstack/solid-virtual`
(динамические высоты). Стили — CSS-переменные (темы), без CSS-in-JS рантайма.
## Почему
Нет VDOM; обновление одной реакции перерисовывает один узел. Рантайм ~7 КБ gzip.
