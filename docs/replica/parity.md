# replica-diff: паритет функций NeoShard ↔ Discord

Источник: `docs/replica/features.csv` (57 функций, 4 — `skip`: Nitro, Activities,
Rich Presence игр, Discovery). Оценка: yes = 1, partial = 0.5.

| приоритет | счёт | доля |
|---|---|---|
| must | 44.0 / 45 | **98%** |
| should | 9.5 / 11 | **86%** |
| could | 0.5 / 1 | 50% |

**51 — полностью, 6 — частично, 0 — отсутствует.**

## Частично (что именно не хватает)

| функция | не хватает |
|---|---|
| стикеры | интерфейса (API есть) |
| push | отправки Web Push |
| шумоподавление | подключения RNNoise к захвату в вебе |
| федерация | федерации гильдий (ЛС между инстансами работают) |
| анонсы | e2e-теста crosspost |
| восстановление пароля | e2e-проверки с SMTP |

## Сверх оригинала

Вся кастомизация профиля бесплатна (рамки, эффекты, темы, стили имени, профили на серверах), ссылки подтверждаются открытым `rel="me"` без сторонних OAuth. Открытый протокол и спецификация, ядро для форков (TDLib-модель), подключение к
любому инстансу, федерация, плагины клиента в песочнице, JSON-темы, сквозное шифрование ЛС (MLS, ключи только на устройстве),
self-hosting одной командой, офлайн-кэш, приватность (никакой сторонней аналитики).

## Где лучше по метрикам

Стартовый JS 69 КБ gzip, ядро 149 КБ gzip (с MLS — 437 КБ, по запросу), десктоп-бинарник 6 МБ, бинарный протокол
с zstd, ~15 КБ памяти сервера на соединение.
