`ecc:security-reviewer`), каждая находка — с регрессионным тестом, где это возможно.

## Проход 2 — веб-клиент (typescript-reviewer): исправлено

Порядок сообщений при наличии неотправленных (тест `state.test.ts`), перемонтирование
строк виртуального списка, черновик уезжал в другой канал (канал теперь keyed),
`javascript:`-URL во вложениях/эмбедах (`safeUrl`), строгая CSP, плагины — отдельная
страница-песочница без сети + код закреплён SHA-256, неполный сброс при выходе,
a11y живой области ленты, IME в редакторе, таймаут `api()`, обработка фоновой вкладки.

## Проход 3 — auth и права (security-reviewer): критичных нет

Исправлено: внутренние отправки (crosspost, ответы ботов, федерация) больше не могут
пинговать `@everyone`; лимит неудачных повторных аутентификаций (5 за 15 мин) и
обязательный 2FA-код для смены пароля/удаления аккаунта/отключения 2FA; аккаунты
без пароля не проходят проверку пароля; доставка федерации через закреплённый клиент;
лимит вебхука расходуется только после проверки токена; overwrites при создании канала
проверяются как в `put_overwrite`; `parent_id` — только категория своей гильдии,
треды не перевешиваются; иконка гильдии — только свой ключ хранилища; имя
`deleted_*` зарезервировано.

**Открыто (Medium/Low, в PROGRESS):** короткий TTL голосовых токенов / удаление из
комнаты при бане; ограничение выборки MLS KeyPackage-ей общими каналами;
лимиты на inbox федерации и `resolve`; лимиты числа тредов/инвайтов/подписчиков и
`OFFSET` поиска; согласие владельца бота на добавление; очистка reset-токенов при
смене пароля; соль для backup-кодов; блокировка входа по (аккаунт, IP).

**Проверено и признано корректным** (по отчёту): argon2id и выравнивание времени,
одноразовость тикетов 2FA и backup-кодов, reset-токены, распространение отзыва
сессий, иерархия ролей и выдача прав, иерархия кика/бана/тайм-аута, проверка бана при
принятии инвайта, 404 для скрытых объектов, привязка сообщений/реакций/закрепов/
вложений к каналу, фильтрация Ready и событий Gateway, подписи федерации.
