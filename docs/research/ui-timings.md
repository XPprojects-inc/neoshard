# Поведенческая спека: тайминги и анимации интерфейса

Наблюдения общего характера о том, как ощущается интерфейс чата этого класса
(не замеры чужого кода). Токены NeoShard — `packages/ui/src/motion/tokens.ts`.

| взаимодействие | ощущение | токен NeoShard |
|---|---|---|
| hover по иконке гильдии | круг → скруглённый квадрат, ~150 мс | `duration.fast` 120 мс, `ease.out` |
| индикатор (pill) слева от гильдии | растёт по высоте, spring | `spring.snappy` (stiffness 500, damping 30) |
| открытие модалки | scale 0.95→1 + opacity, ~200 мс; закрытие быстрее | `duration.base` 200 / exit 150 |
| тост | slide-up + fade, авто-скрытие 4 с | `spring.gentle` |
| контекстное меню | мгновенно, ~100 мс fade | `duration.instant` 80 |
| новое сообщение | без анимации в длинной ленте (иначе шумно); своё — короткий fade | `duration.fast` |
| индикатор набора | три точки, циклическая пульсация 1.2 с | CSS keyframes (дёшево) |
| сайдбар (мобильный) | свайп с инерцией, spring-возврат | `drag()` + `spring.snappy` |

## Правила производительности
- Только `transform` и `opacity`. Никаких анимаций `height/width/top`
  (FLIP вместо них — `layout()`).
- `prefers-reduced-motion: reduce` ⇒ длительности → 0, spring → мгновенный переход;
  сохраняются только fade-ы ≤ 80 мс.
- `will-change` выставляется только на время анимации.
