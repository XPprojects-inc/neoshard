# Безопасность

## Сообщить об уязвимости

Пишите на **security@neoshard.ru** (PGP-ключ — `/.well-known/security.txt`
официального инстанса). Не создавайте публичный issue. Мы подтверждаем получение
в течение 72 часов и согласуем срок раскрытия (обычно до 90 дней).

## Модель угроз (кратко)

- **Сервер — недоверенный для E2EE.** В ЛС/группах с `e2ee` сервер видит только
  шифротекст MLS (RFC 9420) и метаданные (кто, когда, в какой канал).
- **Авторизация** — одна проверка на запрос через общий алгоритм прав
  (`crates/neoshard-proto/src/permissions.rs`), невидимые объекты → 404.
- **Сессии** — opaque-токены, в БД только SHA-256; отзыв мгновенно закрывает
  Gateway-соединения. Пароли — argon2id, 2FA — TOTP с защитой от повтора кода.
- **SSRF** — превью ссылок и федерация: только публичные адреса, адрес
  закрепляется после проверки DNS, без редиректов на внутренние сети.
- **Клиент** — строгая CSP, Markdown без `innerHTML`, только http(s)-ссылки,
  плагины в песочнице без сети с кодом, закреплённым SHA-256.
- **Федерация** — запросы подписаны Ed25519, защита от повторов (nonce + окно 5 мин).

Что проверено и как — `docs/security-review.md`.

## Поддерживаемые версии

Исправления безопасности выпускаются для последней минорной версии.
